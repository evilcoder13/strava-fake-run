# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

Phase 4 adds two download buttons ("Download GPX" and "Download TCX") to the existing Sidebar
`Activity` section. The buttons appear immediately below the `{N} points generated` status line,
conditionally rendered when `generatedActivity !== null`. No new layout regions, no new pages.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (font-normal) | 1.5 |
| Label | 12px (text-xs) | 500 (font-medium) | 1.4 |
| Button | 14px (text-sm) | 500 (font-medium) | 1 (single line) |
| Section heading | 14px (text-sm) | 600 (font-semibold) | 1.2 |

Only 2 weights used: 400 (normal) and the medium/semibold cluster treated as 500-600 per context.
For practical CSS declaration: regular (400) and medium (500) as the two distinct weights; semibold
(600) is reserved for section headings and already established in existing code.

Source: Sidebar.tsx uses `text-sm font-medium` for buttons, `text-sm font-semibold` for headings,
`text-xs text-gray-500` for status copy.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff | Page background, card surfaces (`bg-white`) |
| Secondary (30%) | #F9FAFB (gray-50) | Sidebar sections (`bg-gray-50`), borders (`border-gray-200` = #E5E7EB) |
| Accent (10%) | #FC4C02 | Download GPX button fill, Download TCX button fill |
| Destructive | #EF4444 (red-500) | Not applicable — no destructive actions in this phase |

Accent reserved for: "Download GPX" button background, "Download TCX" button background.
The accent is NOT used for borders, labels, hover rings, or status text in this phase.

Hover state: accent buttons darken to `hover:bg-orange-600` (#EA580C) — consistent with the
existing Generate Activity button pattern.

Disabled state: `disabled:opacity-50 disabled:cursor-not-allowed` — consistent with existing
button pattern. Both download buttons are disabled when `isGenerating` is true (generation in
progress) to prevent export of a partial dataset.

Source: tailwind.config.ts (`orange.500: #FC4C02`), Sidebar.tsx button class string.

## Component Inventory

### ExportButtons (new inline block, not a separate file unless executor prefers)

Placement: inside the existing Activity section `<div>`, after the `{generatedActivity.length} points generated` `<p>` tag.

Conditional render: `{generatedActivity !== null && <ExportButtons />}`

Structure:
```
<div class="mt-2 flex flex-col gap-2">
  <button class="w-full py-2 px-4 bg-[#FC4C02] text-white text-sm font-medium rounded-md
                 hover:bg-orange-600 disabled:opacity-50 disabled:cursor-not-allowed
                 transition-colors flex items-center justify-center gap-1">
    <Download size={16} />
    Download GPX
  </button>
  <button class="w-full py-2 px-4 bg-[#FC4C02] text-white text-sm font-medium rounded-md
                 hover:bg-orange-600 disabled:opacity-50 disabled:cursor-not-allowed
                 transition-colors flex items-center justify-center gap-1">
    <Download size={16} />
    Download TCX
  </button>
</div>
```

Icon: `Download` from lucide-react, size 16px, placed to the left of the label text. Gap between
icon and label: 4px (`gap-1`).

Both buttons are `disabled` when `isGenerating === true`.

### No new layout components needed.

The existing Activity section `<div class="p-4 bg-gray-50 border-b border-gray-200">` is the
container. No new sidebar sections, no new columns, no modals.

## Interaction States

| State | Trigger | Visual |
|-------|---------|--------|
| Buttons hidden | `generatedActivity === null` | Entire button group not rendered (conditional render, not visibility:hidden) |
| Buttons enabled | `generatedActivity !== null && !isGenerating` | Full opacity, cursor pointer |
| Buttons disabled | `isGenerating === true` | `opacity-50`, `cursor-not-allowed` |
| Button hover | Mouse over enabled button | Background shifts from #FC4C02 to #EA580C |
| Download triggered | Click enabled button | Browser native file download dialog — no toast, no modal |

No loading spinners on the download buttons themselves. The download is synchronous (in-memory
string to Blob to anchor click). No async state needed beyond what the existing `isGenerating`
guard provides.

## Constraints and Out-of-Scope

- Do NOT add a progress indicator to the download buttons (download is synchronous).
- Do NOT add a success toast after download (browser native download feedback is sufficient).
- Do NOT reposition the Activity section or change its container styles.
- Do NOT change the Generate Activity button appearance.
- The TCX button is visually identical to the GPX button — same color, size, weight.
- No icon differentiation between GPX and TCX buttons; both use `Download` icon.
