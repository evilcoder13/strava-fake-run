# Plan 05-02: UI Activity Type Selector + Export Sport Type Wiring

## Objective

Add the Activity Type Selector UI to `Sidebar.tsx` (2×2 grid of sport buttons), wire it to the Zustand store, update `exportGPX` and `exportTCX` to accept and encode the correct Strava sport type, and update the Sidebar's export buttons to pass the active sport profile.

## must_haves

- Sidebar has a 2×2 grid of activity type buttons (Run, Walk, Cycle, Hike) with Strava orange active state
- Clicking a button calls `setActivityType(ActivityType.X)` and updates the UI immediately
- `exportGPX` accepts optional `activityType` and injects `<type>{gpxType}</type>` inside `<trk>`
- `exportTCX` accepts optional `activityType` and sets `Sport="{tcxSport}"` on `<Activity>` element
- Sidebar passes `generatedActivity` AND `activityType` to both export functions
- `npx tsc --noEmit` exits 0
