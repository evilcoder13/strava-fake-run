# Plan 06-01: Timezone Selector

## Objective
Update the `route-interpolator` and store to accept and utilize a timezone offset string (`+HH:MM` or `-HH:MM` or `Z`). By respecting the offset at Date parsing time, we encode the correct UTC timestamp that Strava maps to the chosen local timestamp.

## Files to modify
1. `store/useRouteStore.ts`
   - Add `timezoneOffset: string` to `RouteState` and `RouteConfig`.
   - Default it to the local browser offset. Implement `getLocalTimezoneOffsetString()` function which transforms `new Date().getTimezoneOffset()` into `+/-HH:MM`.
2. `lib/route-interpolator.ts`
   - Update `InterpolateOptions` interface to include `timezoneOffset: string`.
   - In `interpolatePath`:
     - Modify `startMs` initialization logic:
       `const startMs = new Date(\`\${startDate}T\${normalizedTime}:00\${timezoneOffset}\`).getTime();`
3. `components/Sidebar.tsx`
   - Create a static list of timezone offsets (`UTC -12:00` to `UTC +14:00`).
   - Add a `<select>` input bound to `timezoneOffset` in the Settings panel next to `startTime`.

## Validation
- `npx tsc --noEmit` completes without error.
- UI displays the correct timezone.
- Exported GPX/TCX files include timestamps shifted correctly.
