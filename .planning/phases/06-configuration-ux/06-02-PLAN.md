# Plan 06-02: Pace Unit Toggle

## Objective
Introduce a UI toggle in the Sidebar that allows users to seamlessly switch between expressing effort as Pace (`min/km`) or Speed (`km/h`).

## Files to modify
1. `store/useRouteStore.ts`
   - Add `useSpeedUnit: boolean` to `RouteState` and `RouteConfig`, defaulting to `false`.
2. `components/Sidebar.tsx`
   - Add a unit toggle button above the Pace input area (e.g., segmented control "min/km" | "km/h").
   - When `useSpeedUnit` is false, display the existing two sliders for Minutes and Seconds.
   - When `useSpeedUnit` is true, display a single numeric `<input>` (or slider) for Speed (`km/h`) ranging from `1.0` to `50.0`.
   - Ensure a robust conversion mechanism inline:
     - `speed = 60 / (paceMinutes + paceSeconds / 60)`
     - Updating speed converts back to `paceMinutes` and `paceSeconds`:
         `totalMinutes = 60 / speed`
         `paceMinutes = Math.floor(totalMinutes)`
         `paceSeconds = Math.round((totalMinutes - paceMinutes) * 60)`

## Validation
- Toggle behavior flawlessly translates values. Setting pace to 5:00 min/km and toggling shows 12.0 km/h. Setting 20 km/h shows 3:00 min/km on toggle.
- TypeScript compiles cleanly.
- Export behavior remains unmodified (as the store format of truth remains `paceMinutes` and `paceSeconds`).
