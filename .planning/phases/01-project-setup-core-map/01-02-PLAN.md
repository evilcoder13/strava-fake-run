# Plan 01-02: State Management & Leaflet Setup

## Goal
Install and configure the mapping libraries (react-leaflet, leaflet) and set up the global Zustand store to hold the route state.

## Requirements

## Verification
- [ ] `leaflet` and `react-leaflet` are installed.

- [ ] Leaflet CSS is imported.
