# Plan 01-03: UI Layout & Map Components

## Goal
Implement the main UI layout holding the map and the sidebar, rendering the route polylines and waypoints.

## Requirements
- MAP-01, MAP-02, MAP-03

## Verification
- [ ] Next.js app builds without SSR document errors.
- [ ] Map click adds a waypoint in Zustand.
- [ ] Polyline draws lines connecting the waypoints based on state.
- [ ] Sidebar renders a list of coordinates with delete buttons.
