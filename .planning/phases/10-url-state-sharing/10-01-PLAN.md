# Plan: 10-01 — State Serialization logic

Implement the functions to convert project state to/from a URL-safe string.

## Proposed Changes

### `lib/url-state.ts` (New)
- `encodeState(state: RouteState): string`
    - Pulls `waypoints` (just coords), `pace`, `time`, `activityType`, `timezone`.
    - `JSON.stringify` -> `encodeURIComponent` -> `btoa` (safely).
- `decodeState(base64: string): Partial<RouteState> | null`
    - Inverse logic with error handling.

### `store/useRouteStore.ts`
- Add `loadFromState: (state: Partial<RouteState>) => void` action to allow batch updates from the URL.

## Verification Plan
- Unit test for `encodeState` and `decodeState`.
- Verify that large waypoint arrays are handled without overflow.
