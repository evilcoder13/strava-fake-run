# Plan: 09-02 — Address Search via Nominatim

Implement a search input that enables users to find specific addresses.

## Proposed Changes

### `components/Sidebar.tsx`
- Add a text input with a `Search` icon (Lucide `Search`).
- Implement `handleSearch` function:
    - Debounce input (optional but good).
    - Fetch `https://nominatim.openstreetmap.org/search?format=json&q={query}&limit=5`.
    - Set custom `User-Agent: StravaFakeRun/1.0`.
- Display a small dropdown or just fly to the top result on "Enter".
- Trigger `flyTo` action on result selection.

### `components/MapComponent.tsx`
- Ensure any search result markers are handled or simply centering is enough. (Centering is enough for MVP).

## Verification Plan
- Type "London" and press enter. Verify map centers on London.
- Type "1600 Pennsylvania Ave" and verify it centers on the White House.
- Ensure empty input or no results doesn't crash the app.
