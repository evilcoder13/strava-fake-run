# Plan 02-01: Integrate snap-to-road API

<objective>
Update `useRouteStore` to fetch and store a snapped path from OSRM whenever waypoints change, and update the `Map` component to render this snapped path using the `Polyline` component instead of drawing straight lines between points.
</objective>

<read_first>
- store/useRouteStore.ts
- components/Map.tsx
</read_first>

<tasks>
1. **Extend `useRouteStore.ts`**:
   <action>
   - Add `snappedPath: [number, number][]` to `RouteState`.
   - Initialize `snappedPath` to `[]`.
   - Add an asynchronous action: `fetchSnappedPath: () => Promise<void>`.
   - Inside `fetchSnappedPath`:
     - Access `get().waypoints`. If there are fewer than 2 waypoints, set `snappedPath: []` and return.
     - Extract coordinates and construct the OSRM endpoint URL:
       `https://router.project-osrm.org/route/v1/foot/${lon1},${lat1};${lon2},${lat2}...`
     - Append `?overview=full&geometries=geojson` to the URL.
     - `fetch()` the URL. If the request fails, map point-to-point as fallback: `waypoints.map(w => [w.lat, w.lng])`.
     - Extract geometry: `json.routes[0].geometry.coordinates`
     - Map OSRM `[lon, lat]` to Leaflet `[lat, lon]`: `coords.map(([lon, lat]: [number, number]) => [lat, lon])`. Set to `snappedPath`.
   - In `addWaypoint`, `removeWaypoint`, `reorderWaypoints`, and `moveWaypoint`: call `get().fetchSnappedPath()` inside or after their store updates. Let it be `async` or fire-and-forget. (Zustand updates synchronously, so `get().fetchSnappedPath()` will read the updated array).
   </action>
   <acceptance_criteria>
   - `useRouteStore.ts` exports `snappedPath` as an array.
   - OSRM fetch string contains `https://router.project-osrm.org/route/v1/foot/`.
   - Array mapped from `[lon, lat]` to `[lat, lon]` before saving to `snappedPath`.
   - Functions updating waypoints trigger `fetchSnappedPath()`.
   </acceptance_criteria>

2. **Update Map Component (`components/Map.tsx`)**:
   <action>
   - Substitute existing `Polyline` logic.
   - Read `snappedPath` from store: `const snappedPath = useRouteStore((state) => state.snappedPath);`
   - Render: `<Polyline positions={snappedPath} color="#FC4C02" weight={4} />`.
   </action>
   <acceptance_criteria>
   - `Map.tsx` imports `snappedPath`.
   - `<Polyline>` is rendered using `positions={snappedPath}`.
   </acceptance_criteria>
</tasks>

<verification>
- When 2 or more waypoints are added, `snappedPath` populates from OSRM and follows real road geometry.
</verification>
