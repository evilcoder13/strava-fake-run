# Plan 02-02: Build Configuration sidebar UI

<objective>
Introduce date, time, pace, and noise configuration fields in the Sidebar, bound to global state, enabling users to parameterize their synthetic run.
</objective>

<read_first>
- store/useRouteStore.ts
- components/Sidebar.tsx
- .planning/phases/02-ui-controls-road-snapping/02-UI-SPEC.md
</read_first>

<tasks>
1. **Extend global state in `useRouteStore.ts`**:
   <action>
   - Add new config state properties to `RouteState`:
     - `startDate: string` (YYYY-MM-DD, default today, e.g. `new Date().toISOString().split('T')[0]`)
     - `startTime: string` (HH:MM, default "08:00")
     - `paceMinutes: number` (default 5)
     - `paceSeconds: number` (default 30)
     - `useNoise: boolean` (default false)
   - Add setters for these fields: `setConfig: (config: Partial<RouteState>) => void`.
   </action>
   <acceptance_criteria>
   - `useRouteStore.ts` exports `startDate`, `startTime`, `paceMinutes`, `paceSeconds`, `useNoise`.
   - The store correctly exposes `setConfig`.
   </acceptance_criteria>

2. **Build Configuration UI in `Sidebar.tsx`**:
   <action>
   - Add a configuration panel segment below the app header and above the waypoints list.
   - Use standard `<input>` elements formatted with Tailwind classes (e.g., `border`, `rounded`, `p-1`, `text-sm`).
   - UI Header: `<h2 className="text-sm font-semibold text-gray-900 mb-3">Run Settings</h2>`
   - Implement fields for:
     - "Start Date" (`type="date"`) tied to `startDate`. Set via `setConfig({ startDate: e.target.value })`.
     - "Start Time" (`type="time"`) tied to `startTime`. Set via `setConfig({ startTime: e.target.value })`.
     - "Target Pace (min/km)" combining two numeric inputs (for minutes and seconds) separated by a colon. Bind to `paceMinutes` and `paceSeconds`.
     - "Enable Pacing Noise" using a toggle checkbox `<input type="checkbox" className="accent-[#FC4C02]">`. Bind to `useNoise`.
   - Add styling consistent with `02-UI-SPEC.md` colors and spacing.
   </action>
   <acceptance_criteria>
   - `Sidebar.tsx` renders `<input type="date">`, `<input type="time">`, and two pace inputs.
   - `Sidebar.tsx` contains exact wording "Target Pace (min/km)", "Enable Pacing Noise", "Start Date", "Start Time", "Run Settings".
   - Input changes trigger `setConfig`.
   </acceptance_criteria>
</tasks>

<verification>
- Changing the pace minutes/seconds in the UI updates the global Zustand store accordingly.
- Toggling noise changes the `useNoise` state in the store.
</verification>
