# Plan: 07-02 — GPS Noise Layer

Apply Gaussian coordinate perturbation to each ActivityPoint to avoid "perfectly straight" robotic GPS traces.

## User Review Required

> [!NOTE]
> Noise is only applied if "Enable Pacing Noise" is checked in the UI.

- **Spatial Variance**: ~1-2 meters.
- **Implementation**: Box-Muller transform applied to `lat` and `lon` individually.

## Proposed Changes

### `lib/biometric-simulator.ts`
- Export `gaussianRandom` (currently internal) to allow reuse for GPS noise.

### `store/useRouteStore.ts`

#### [MOD] `generateActivity`
- Inside the `activity.map` loop, if `state.useNoise` is true:
    - Apply small random offset to `lat` and `lon`.
    - `OFFSET_SCALE = 0.00001` (~1.1 meters).

## Verification Plan

### Manual Verification
- Generate a long straight road activity with noise ON.
- Zoom in on the GPX track in a viewer; it should show slight "wiggles" instead of a mathematical line.
- Verify with noise OFF, the track remains perfectly snapped to the road.
