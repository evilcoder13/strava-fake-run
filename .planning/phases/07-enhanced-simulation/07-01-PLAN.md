# Plan: 07-01 — Gradient & Ramp Simulation

Implement gradient-responsive biometrics and warm-up/cool-down ramps to enhance workout realism.

## User Review Required

> [!IMPORTANT]
> This change introduces automatic HR spikes on climbs and drops in cadence. The intensity of these effects is tuned for a "standard" athlete.

- **Warm-up/Cool-down Duration**: Fixed at 5% of total time.
- **Gradient Sensitivity**: A 10% grade will trigger a ~15bpm HR increase.

## Proposed Changes

### `lib/biometric-simulator.ts`

#### [MOD] `computeHR`
- Add `gradient: number` and `progress: number` to options.
- Calculate `rampFactor`:
    - if progress < 0.05: scale linearly from 0 to 1.
    - if progress > 0.95: scale linearly from 1 to 0.
    - else: 1.0.
- Use `profile.restingHR` as floor.
- `targetHR = restingHR + (hrr_fraction * (maxHR - restingHR))`.
- `adjustedHR = restingHR + (targetHR - restingHR) * rampFactor`.
- Add `gradient` bonus: `climbBonus = Math.max(0, gradient * 150)`. (10% = 15bpm).

#### [MOD] `computeCadence`
- Add `gradient: number` to options.
- Adjust cadence based on gradient:
    - `cadence = target - (gradient * 200)`. (10% uphill = -20 cadence).

### `store/useRouteStore.ts`

#### [MOD] `generateActivity`
- Calculate `gradient` for each point (except first).
- Calculate `progress` (`i / (points.length - 1)`).
- Pass these to `computeHR` and `computeCadence`.
